# Sakhi – Women Safety Application

**Sakhi** is a women safety mobile application designed to provide instant help during emergency situations. The app focuses on quick SOS alerts, real-time location sharing, and smart safety features to enhance personal security.

---

## Objective

The primary objective of the **Sakhi** project is to empower women by providing a reliable and fast emergency response system using mobile technology, ensuring safety anytime and anywhere.

## Features

- **Automated SOS Alert:** Sends emergency alerts to pre-registered contacts.
- **Live Location Sharing:** Shares real-time GPS location during emergencies.
- **One-Tap Emergency Button:** Quick access to trigger SOS instantly.
- **Live Camera Feed:** Captures images/videos for evidence (future enhancement).
- **Safe Route Navigation:** Suggests safer travel routes (planned feature).
- **Background SOS Trigger:** Works even when the app runs in background (planned).

## 🛠️ Technology Stack

- **Platform:** Cross-platform (Android, iOS-ready)
- **Framework:** Flutter
- **Programming Language:** Dart
- **Location Services:** Flutter Map & Geolocator
- **Backend:** Firebase Authentication
- **Database:** Firebase Firestore / Realtime Database
- **Tools:** Android Studio, VS Code, GitHub, Firebase Console

## 🧩 System Workflow

1. User registers and adds emergency contacts
2. SOS button is triggered during emergency
3. Live GPS location is fetched
4. Emergency alert is sent to trusted contacts
5. Optional media capture for safety evidence

## Future Enhancements

- AI-based threat detection
- Voice-activated SOS
- Integration with police & emergency services
- Wearable device support
- Community-based safe zone alerts
