<h1 align="center"> Sakhi – Women Safety Application</h1>

<p align="center">
  <strong>Sakhi</strong> is a women safety mobile application designed to provide instant help during emergency situations.
  The app focuses on quick SOS alerts, real-time location sharing, and smart safety features to enhance personal security.
</p>

<hr>

<h2> Objective</h2>
<p>
  The primary objective of the <strong>Sakhi</strong> project is to empower women by providing a reliable and fast emergency
  response system using mobile technology, ensuring safety anytime and anywhere.
</p>

<h2> Features</h2>
<ul>
  <li><strong>Automated SOS Alert:</strong> Sends emergency alerts to pre-registered contacts.</li>
  <li><strong>Live Location Sharing:</strong> Shares real-time GPS location during emergencies.</li>
  <li><strong>One-Tap Emergency Button:</strong> Quick access to trigger SOS instantly.</li>
  <li><strong>Live Camera Feed:</strong> Captures images/videos for evidence (future enhancement).</li>
  <li><strong>Safe Route Navigation:</strong> Suggests safer travel routes (planned feature).</li>
  <li><strong>Background SOS Trigger:</strong> Works even when the app runs in background (planned).</li>
</ul>

<h2>🛠️ Technology Stack</h2>
<ul>
  <li><strong>Platform:</strong> Android</li>
  <li><strong>Programming Language:</strong> Java / Kotlin</li>
  <li><strong>Backend:</strong> Firebase (Authentication & Database)</li>
  <li><strong>Location Services:</strong> Google Maps API</li>
  <li><strong>Database:</strong> Firebase Firestore / Realtime Database</li>
  <li><strong>Tools:</strong> Android Studio, GitHub</li>
</ul>

<h2>🧩 System Workflow</h2>
<ol>
  <li>User registers and adds emergency contacts</li>
  <li>SOS button is triggered during emergency</li>
  <li>Live GPS location is fetched</li>
  <li>Emergency alert is sent to trusted contacts</li>
  <li>Optional media capture for safety evidence</li>
</ol>

<h2> Future Enhancements</h2>
<ul>
  <li>AI-based threat detection</li>
  <li>Voice-activated SOS</li>
  <li>Integration with police & emergency services</li>
  <li>Wearable device support</li>
  <li>Community-based safe zone alerts</li>
</ul>
